Selection sort
What loop invariant does this algorithm maintain?

Init:
    When i = 0, then A[0:i] is empty, thus sorted?

Maintenance:
    Assume that A[0:(i-1)] is sorted
    The A[i:n] part isn't sorted
    We find smallest element inside A[i:n] at j
    And swap A[i] with A[j]
    Which makes A[0:i] sorted

Termination:
    loop executes until i >= n - 1
    at this point the A[i:n] contains single element
    which is maximum


Why does selection sort run n - 1 times?
Because the loop iteration searches for minimum element from i to the end and for the last iteration (if we run over n times) we will find minimum element from one element which doesn't necessary.

Worst-case running time:
outer loop: n-1 times
inner loop: n-i-1
so its:

o = 0
for i in 0..<(n-1):
    o += n - i - 1

Best-case scenario is same because we will always check for min element
